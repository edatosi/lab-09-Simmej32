# [LAB-9]: Taller – Lista enlazada con pruebas

Implementar una lista simplemente enlazada genérica hasta que **todas las pruebas pasen**.

| Archivo | ¿Se modifica? |
|---|---|
| `src/main/java/listas/ListaEnlazada.java` | **Sí.** Busque los comentarios `TODO` y reemplace el `throw new UnsupportedOperationException(...)`. |
| `src/main/java/listas/Nodo.java` | No (ya está completo). |
| `src/test/java/listas/ListaEnlazadaTest.java` | **No.** Son las pruebas. |


## Evaluación

La nota (de 0.0 a 5.0) se calcula con estos criterios:

| Criterio | Peso | Qué se evalúa |
|---|---|---|
| Calidad del código | 20% | Comentarios y nombres de variables claros |
| Pruebas aprobadas | 60% | Resultado de las pruebas en GitHub Actions |
| Mensajes de commit | 10% | Claros y descriptivos |
| Pull Request | 10% | Creado correctamente |
